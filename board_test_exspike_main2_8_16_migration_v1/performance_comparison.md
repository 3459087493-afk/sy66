# 性能与精度比较

| 类别 | 已验证基线 | Migration V1 | 当前结论 |
|---|---:|---:|---|
| Top-1 Accuracy | 1000/10000 正式准确率无已完成可信记录 | pilot 20/20；正式 1000 正在运行 | pilot 不能替代正式 Top-1 |
| 端到端延迟 | 16.531326 s/image | 16.895528 s/image（20 图均值） | 慢 0.364202 s，+2.20% |
| 全部 Kernel | 6.640336 s/image，30 calls | 7.146935 s/image，34 calls | +0.506599 s，+7.63%；30 matrix + 4 attention |
| 非 Kernel | 约 9.890990 s/image | 约 9.748593 s/image | 减少约 0.142397 s，但不足以抵消新核开销 |
| 吞吐率 | 0.060491 image/s | 0.059187 image/s | 下降 2.16% |
| 资源 | LUT 3047, FF 2144, DSP 8, BRAM 10.5 | LUT 5519, FF 3622, DSP 8, BRAM 13.5 | Vivado 实现后事实 |
| 时序 | 100 MHz 通过 | 100 MHz, WNS +0.218 ns, TNS 0 | 收敛 |
| Vivado 片上功耗 | 同口径待补 | 1.444 W vectorless | 不能代表整板 |
| 整板功耗 | 待测 | 待测 | 需仪表实测 |

已证明 V1 真正在 RTL 中执行 QK^T、Attention×V、0.125 和 attention LIF，不是复制旧 bitstream；整图板端输出与软件参考完全一致。pilot 同时证明本实现没有降低端到端延迟，主要原因是调用从 30 增到 34 且 Q/K/V 独立搬运。下一优先级应是融合 Attention 与相邻投影/事件生成、减少启动与搬运，而不是继续孤立增加核。正式精度与整板功耗仍待测。

正式 1000 张任务已启动并通过首个原子保存点：当前快照 10/1000、10 正确，均值 17.271793 s/image、Kernel 7.165273 s/image。该数字仅用于确认任务健康，最终 Top-1 和正式均值必须等 1000 张完成。
